# S02_ASSETS.md — Everything Scene 2 (Legend) needs

Scene 2: rise from black on a carved ankhi-jhyal lit from inside → through it into Bali Raja's
chamber at night → Jamuna (from behind) with a diyo at his deathbed → cold light from the
doorway, **Yamaraj only as a crowned shadow** across the floor → turn back to the window, crow
on the sill lifts off and wipes the lens. ~170 frames. See `SCENES.md` row 2.

## Status key

| Tag | Meaning |
| --- | --- |
| **FOUND** | Good free asset found; Claude downloads it and credits it |
| **AI** | Not found, or what exists is poor or wrong style. **Owner generates it with AI** (prompt given below) |
| **AI?** | Found something usable but weak; AI would look better. Owner's choice |
| **BUILD** | Claude models or simulates it in Blender (simple geometry, cloth, lights, FX) |
| **REUSE** | Already in the project |

Where AI files go: `blender/assets/s02/ai/<name>.glb` (GLB with PBR textures embedded).
Each AI asset gets a `CREDITS.md` line: "AI-generated by the owner (<tool>)".

## AI generation list (owner)

**Reference photos** for every item are in `refrences/s02_ai/<item>/` (local only, never
committed). `refrences/s02_ai/SOURCES.md` lists each photo's title, licence and Commons link.
They are visual reference only: never use them as textures or publish them.

How to use them:
- **Image-to-3D input**: use a photo marked ★ below. It shows one object, isolated or clearly
  framed, so an image-to-3D tool can read it directly.
- **Style reference**: the other photos show the carving, wood colour and patina. Use them with
  the text prompt, or as a second / style image if your tool takes one.
- One object per generation, neutral background, no base or plinth, aged and realistic (not
  shiny or game-like), PBR textures, export **GLB** to `blender/assets/s02/ai/<file>`.
  Claude scales each to the real size given here.
- Negative prompt (if your tool has one): `cartoon, toy, low detail, plastic, glossy, base, plinth, text, watermark`.
