# तिहार — The Road of Lights

A realistic, scroll-driven 3D explainer of why Tihar is celebrated in Nepal.
Entry for the KUCC Tihar-Chhath Web UI Design Competition.

Scenes are rendered in Blender (Cycles); the website scrubs through the rendered
frames as you scroll, with Nepali captions and a live UI layer on top.

- Story and scenes: `docs/SCENES.md`
- Assets and licences: `docs/ASSETS.md`, `docs/CREDITS.md`
- Render pipeline: `docs/PIPELINE.md`
- Website: `docs/WEB.md`
- Instructions for Claude Code: `CLAUDE.md`

## Run

```
cd web
npm install
npm run dev
```
